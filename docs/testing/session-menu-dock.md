# セッションメニューのドック

ドックは `SessionMenu` 内の固定した親に一度だけ描画し、メニュー開閉時は CSS で配置を変える。操作・ストアは従来のものを使う。シート本文とドックを別のグリッド行に分け、スマホのホームナビと「その他」の背景は本文側に収める。ポップアップは既存の body ポータルと画面内補正を使い、トリガーの位置変更・切断、リサイズ時に閉じる。Escape はポップアップで処理し、ホームまで同時に閉じない。

## 自動確認

依存パッケージと Playwright が使える環境で Vite を起動し、以下を実行する。Playwright のモジュール指定、Vite の URL、ブラウザの実行ファイルは引数で変更できる。依存パッケージの追加は行わない。

```sh
node scripts/test-session-dock-browser.mjs playwright http://127.0.0.1:5173
node scripts/test-volume-slider-browser.mjs
npm run typecheck
npm run build
npm run test:client
npm run test:volume
npm run check:completion
```

新しいブラウザスクリプトは一時 HTML を作って Vite から実際の `WorldScreen`・`Home`・Popover を読み込み、終了時に HTML を消す。実サーバーへの参加・音声接続は行わず、接続状態をストアに設定する。PC の 2D・3D、スマホの縦横・狭幅で、ドックの単一性と DOM の保持、開閉時の状態保持、共有の表示と無効条件、本文スクロール後の到達性、「その他」との重なり、Popover の Escape・再クリック・外側クリック、音量ドラッグ、回転時の閉じ方、非参加時のホームへの復帰を検査する。既存の音量スクリプトはスライダーの描画・入力を別途確認する。

## この環境での結果

- `git diff --check` は成功。
- 指定の npm コマンド、既存の音量ブラウザスクリプト、新しいドックのブラウザスクリプトは、すべて Volta のディレクトリ作成権限エラーで起動できなかった。worktree に `node_modules` もない。型チェック・ビルド・テスト・完了チェックは未通過。
- ブラウザ検証スクリプト自体も未実行。PC の 2D・3D、スマホ縦横の描画、実際の音・リアクション選択、音量反映・保存、画面共有開始・停止、音声接続中のマイク、退出、ポインターロックと表示切替中の制限、非参加時ホームの見た目の比較は未確認。
- 実セッションで「開く→本文スクロール→各操作→閉じる→再度開く」を確認し、マイク有効／無効、自分・他者の共有中、音声未接続、回転後の操作への到達性を確かめる必要がある。
