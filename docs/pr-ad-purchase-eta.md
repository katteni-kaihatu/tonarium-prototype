# AD研究所の購入待ち時間に生産連鎖を反映

## 利用者向けの変更

- 次元の購入待ち時間に、第8次元から下位次元を経て反物質が増える生産連鎖を反映する。
- 「+1」は単価、「+n」は次の10個の区切りまでの全額が貯まる時間を表示する。現在の反物質の生産量がゼロでも、上位次元から生産できる場合は待ち時間を表示する。

## 予測の前提

現在の数量・購入済みの強化を使い、将来の手動購入・自動購入・リセットは含めない。`totalTime`・`runTime` の時間依存倍率と、`ipGen` によるIP増加が `unspentIp` 倍率へ及ぼす影響は、予測開始時の値に固定する。実際の状態更新時に予測し直す。

固定係数で100msずつ進めた生産連鎖を二項係数でまとめて評価する。9999日以内を最大34回の探索で調べ、隣接する刻みの間を直線で補間する。比較対象の100ms反復で最初に到達する時刻との差は最大0.1秒（数値の丸めを除く）。第1次元だけの場合は従来の不足額÷毎秒生産量を使う。

- 型チェック、ビルド、変更履歴チェック、翻訳メタデータ検証が成功。`check:completion` を構成する全チェックを個別に実行した。`npm run check:completion` 自体は上記の権限エラーで起動できていない。
