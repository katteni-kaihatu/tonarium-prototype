# AD研究所の統計・実績・ランキングをタブから直接開く

統計にまとまっていた実績とランキングを、それぞれ既存のタブ列から直接開けるようにした。統計には従来の8項目を残し、実績とランキングは既存の表示処理を専用パネルへ移した。ゲーム進行、実績判定、ランキング集計・送信、同期・保存形式は変更していない。

## 利用者向けの変更

- Infinity前から「統計」「実績」「ランキング」を直接選べる。
- 狭い画面ではタブ名を一行で表示し、収まらないタブは左右にスクロールして選べる。
- 日本語・英語・韓国語の既存訳を使い、開いたままの言語変更にも対応する。ランキングの展開・本人表示・更新・失敗通知は引き続き使える。

## 検証

通常の `npm run` は、すべてVoltaのディレクトリ作成権限エラーで起動前に停止した。代わりに、既存のNode v24.22.1と対象リポジトリに配置済みの依存パッケージを使い、以下のpackage.jsonのスクリプト本体を実行した。依存パッケージの追加はしていない。

- `test:ad`：65件と148件が成功。固定したデータと時刻で統計の8項目・実績の達成数と総数・既知と未知の実績・達成と未達成・保存内容の保持を三言語で確認した。空のランキングと複数パネルのID重複も確認した。
- `test:ad-server`：9件成功。
- `test:i18n`：22件成功。
- `typecheck`、`check:changelog`、`check:content-locales`：成功。
- ビルド：標準の読み込み方式では一時ファイル作成が権限エラーになったため、`vite build --configLoader runner` で成功。
- `git diff --check`：成功。Git LFSの作業領域が書き込み範囲外のため、読み取り時だけLFSフィルターを無効にして確認した。作業開始時から差分として見えるリリースZIPには触れていない。

ブラウザ検証は、`node scripts/verify-ranking-browser.mjs` で合成データ用サーバーを起動し、`node scripts/test-ranking-browser.mjs <Playwrightのmodule URL> <Chrome実行ファイル>` で実行する。既存のPlaywrightとChrome 153を引数で指定した。

ランキング単体の順位、各列、本人表示、展開と折りたたみ、並べ替え時の展開状態、実際の更新ボタンによる呼び出し回数、更新拒否時の通知、Tab・Enter・Space、フォーカス表示、横スクロールを確認した。研究所パネル全体でも、三言語、Infinity前後、幅320・639・640・641・655・656・657・900pxで全表示タブの選択と本文の切り替えを確認した。320pxではタッチ操作、ほかの幅ではマウス操作を使い、全幅でキーボード操作も確認する。Infinity未到達へ戻したときの次元タブへの復帰と、統計・実績・ランキングを開いたままの言語変更も対象とした。
